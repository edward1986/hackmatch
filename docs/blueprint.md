# **App Name**: HackMatch

## Core Features:

- Hackathon Creation: Organizers create hackathons specifying details such as description, timeline and rules.
- Hackathon Sign-Up: Users can sign up for hackathons. Supports the participant role.
- Leaderboard Display: Display a leaderboard, with team rankings.
- Team Matchmaking: AI suggests potential teammates to participants. This is done via a call to an external LLM tool.
- Project Submission: Participants submit project details, and upload associated files. This is needed to get the project judged.
- Timeline Visualization: Visual representation of the hackathon timeline.

## Style Guidelines:

- Primary color: Saturated blue (#3498DB) to convey trust and innovation. This references the innovative spirit of a hackathon.
- Background color: Light gray (#ECF0F1), for a clean, modern backdrop. This is a desaturated version of the blue hue chosen for the primary color.
- Accent color: Yellow-orange (#F39C12) for CTAs, to draw the eye.
- Clean, modern font for readability and professional appearance.
- Card-based design to organize and display hackathon details, project submissions, and team information.
- Subtle transitions and animations on interactions to enhance user experience.
